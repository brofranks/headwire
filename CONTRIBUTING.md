# Contributing

Submit one commit per pull request.

Sign off your commit with `git commit -s` to certify the
[Developer Certificate of Origin](https://developercertificate.org/).

Use `directory/package: lowercase imperative description` for the commit
subject. Separate the body with a blank line, explain what changed and why,
and reference an applicable issue, e.g. `Fixes #N` or `Updates #N`.
