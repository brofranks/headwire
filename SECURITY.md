# Security

Report vulnerabilities privately through GitHub's
[security advisory form](https://github.com/brofranks/headwire/security/advisories/new),
not in a public issue. Report issues in the embedded Tailscale engine, such as
WireGuard, DERP or discovery, to Tailscale as its
[security policy](https://github.com/tailscale/tailscale/blob/main/SECURITY.md)
describes.
